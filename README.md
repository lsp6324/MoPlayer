# MoPlayer

一个用于本地视频、图片浏览与快速分类的 Windows 便携播放器。

## 主要功能

- **播放与看图**：常见视频格式、续播、全屏；图片缩放和平移。
- **标签、评分、收藏**：父子标签、五心评分，支持右键和批量操作。
- **媒体库**：搜索、组合筛选、列表／网格视图，以及多种排序。
- **可选归档**：按收藏、评分、标签整理目录；关闭后只保存标记，文件留在原位。多标签归档使用 NTFS 硬链接。
- **接管旧目录**：先预览，再导入库记录和目录标记，保留本地文件位置。
- **外观设置**：浅色／深色主题、自定义强调色和背景。

## 使用

解压便携包，运行 `MoPlayer.exe`；拖入文件夹或单个视频即可浏览、播放。

数据与设置保存在程序旁 `data`，VLC 配置保存在 `portable`，默认归档目录为 `video`。升级时保留这些目录。删除操作默认只清软件记录，勾选后才回收本地文件。

常用快捷键：`空格` 暂停／播放，`A/D` 或方向键跳转，`X/Z` 切换，`Enter` 全屏，`Q` 标签，`R` 评分，`W` 收藏。
