# MoPlayer

哥们为了能爽快看片并且快速分类，找Astra大人许愿的看片·究极兵器。

根据按Q添加的Tag跟按R进行的评分快速分类且用硬链接让视频分身，同时出现在多个文件夹里但是只占一份硬盘空间。

纯AI项目，但是你跟你弟弟能用就行了管那么多干嘛？

## 基础功能

- 本地视频播放：拖入文件夹，双击播放，支持 MP4、MKV、AVI、MOV、WMV、WebM 等常见格式。
- 目录浏览：保留文件夹层级、自然排序，显示视频缩略图。
- 历史与收藏：记录播放进度，支持续播和收藏。
- 快捷操作：空格暂停，A/D 或方向键跳转 5 秒，X/Z 切换视频，Enter 视频全屏。

## 亮点功能

- **边看边分类**：按 Q 选标签，按 R 评分，按 W 收藏。
- **跳转进度提示**：快进或后退时，左上角显示前后时间、总时长和进度百分比。
- **标签自由归类**：支持多标签、父子标签嵌套、拖动归类和右键删除。
- **五颗心评分**：每颗心支持半颗，准确对应 0～10 分。
- **自动整理文件**：按评分和标签归档，文件名同步加入评分与标签。
- **多标签只占一份空间**：通过 NTFS 硬链接，让同一视频出现在多个分类目录。
- **自选存储位置**：首次运行选择目录，之后可在右上角设置中更改。
- **删除后接着看**：Ctrl+D 将选中或正在播放的视频移入回收站，成功后自动播放下一条。
- **便携与自定义背景**：解压即可运行，支持设置自己的背景图。
- **紧凑界面**：左侧文件、最近和收藏列表；分类操作集中在播放栏，音量、倍速、评分和标签使用浮层；支持浅色、深色和内嵌标题栏。

解压便携包后运行 `MoPlayer.exe`，保留整个程序文件夹即可。多标签归档需要可写的 NTFS 磁盘。
