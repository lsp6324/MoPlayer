# MoPlayer

哥们为了能爽快看片并且快速分类，找Astra大人许愿的看片·究极兵器。

根据按Q添加的Tag跟按R进行的评分快速分类且用硬链接让视频分身，同时出现在多个文件夹里但是只占一份硬盘空间。

纯AI项目，但是你跟你弟弟能用就行了管那么多干嘛？

## 基础功能

- 本地视频播放：在左侧“文件”页拖入文件夹后双击播放，也可直接拖入单个视频，自动加载所在目录并续播目标；支持 MP4、MKV、AVI、MOV、WMV、WebM 等常见格式。保存分类期间连续拖入视频，保存完成后播放最后选择的一个。
- 目录浏览：列表显示当前目录的子文件夹和视频，双击文件夹进入；顶部路径及上一级按钮返回，长路径可展开菜单。各级视频卡片始终左对齐，并记住目录的选择和滚动位置；保留自然排序与视频缩略图。
- 看图集：JPG、PNG、BMP、WebP、GIF、TIFF 与视频混在同一目录和同一顺序里，按 X/Z 直接翻页；滚轮以鼠标位置为中心缩放，拖拽平移，双击在适应窗口和 100% 之间切换，全屏同样可用。手机竖拍照片按 EXIF 方向自动摆正。
- 目录自动更新：外部新增、删除或改名后，导入目录及子目录列表自动更新，保持选择和滚动位置；更新不重载正在播放的视频。分类文件任务期间的变化会在任务完成后补上。
- 历史与收藏：记录播放进度，支持续播和收藏。
- 快捷操作：空格暂停，A/D 或方向键跳转 5 秒，X/Z 切换视频，Enter 视频全屏。

## 亮点功能

- **边看边分类**：按 Q 选标签，按 R 评分，按 W 收藏。图片同样可以打标签、评分、收藏和改名。
- **跳转进度提示**：快进或后退时，播放画面居中偏上的浮层显示前后时间、总时长和进度百分比，文字清晰度不受视频分辨率影响。
- **全屏观看**：移动鼠标显示顶部标题、底部控制栏和光标，空闲后一起隐藏；换片和分类更新保持视频区域尺寸不变。
- **标签自由归类**：支持多标签、父子标签嵌套、拖动归类和右键删除。
- **五颗心评分**：每颗心支持半颗，准确对应 0～10 分。
- **可选归档依据**：在“设置 → 归档设置”中分别勾选标签、评分、收藏，按启用的层级整理目录；不勾选只省略目录，不影响这些信息本身。
- **保存后整理全库**：归档设置保存后同步整理全部已归档视频，未归档视频保持原位置；收藏分类分为“已收藏”和“未收藏”，三个选项都关闭时直接存入归档根目录。文件名保持原名，评分、标签和收藏均不加入文件名。
- **分类保存持续播放**：保存标签、评分及收藏分类时保持当前视频播放或暂停，进度和定位仍可使用。新目录确认后提交分类，旧入口独立清理；正在播放的原路径在释放媒体后清理，占用失败可从“文件任务”单独重试，不阻止后续分类。
- **独立显示分类信息**：文件名前用标签胶囊展示分类，下一行显示收藏星标与状态、五颗心和评分数字。普通窗口与全屏共用这套展示。
- **原位修改文件名**：普通标题悬停后点击右侧铅笔，文件名原位置直接输入；默认选中扩展名前的名称，Enter 保存，Esc 或点击外部取消。错误就地提示，不覆盖同名文件；所有已登记分类入口一起改名，新名称用于后续归档。
- **旧文件恢复原名**：升级启动后，自动恢复有原名记录的已归档视频，保留现有目录；中断可从文件任务恢复，没有可靠原名记录的不会猜测改名。
- **多标签只占一份空间**：通过 NTFS 硬链接，让同一视频出现在多个分类目录。
- **归档位置**：默认使用程序旁的 `video` 文件夹，首次运行无需选择目录；可在右上角归档设置中更改，已有自选位置保留。
- **删除后接着看**：Ctrl+D 将选中或正在播放的视频移入回收站，成功后自动播放下一条。
- **便携与自定义背景**：解压即可运行，支持设置自己的背景图。
- **全窗背景**：背景覆盖顶栏、资料库、播放栏和未播放的主区域；列表使用半透明底层，开始播放后视频画面正常显示。更换背景与调节强度保持播放，取消设置恢复原样。
- **自定义强调色**：外观设置提供一行预设色块、可拖动色板和 R/G/B 数值调节。即时预览，保存后保留，取消恢复原色；普通窗口与全屏控制栏统一跟随颜色，并自动调整文字与图标的深浅。
- **紧凑界面**：左侧文件、最近和收藏列表；分类操作集中在播放栏，音量、倍速、评分和标签使用浮层；支持浅色、深色和内嵌标题栏。

解压便携包后运行 `MoPlayer.exe`，保留整个程序文件夹即可。多标签归档需要可写的 NTFS 磁盘。

应用数据库、设置、日志、背景副本和视频列表缩略图保存在程序旁 `data`；临时文件在 `data/temp`，应用默认 Qt 设置在 `data/qt-settings`。VLC 的配置和缓存使用程序旁 `portable`，Qt 可选的 OpenGL 磁盘着色器缓存已禁用。程序目录不可写时会提示换到可写位置，不把资料库转存到 AppData。

默认归档位置以相对标记保存，始终对应当前程序旁的 `video`；首次归档会自动创建目录。自选的其他归档位置仍按绝对路径保存。移动已有资料库不代表数据库内的视频绝对路径会自动重建；请保留视频的实际位置。

资源管理器的视频缩略图支持为可选系统集成，只有手动启用才下载和注册组件；组件、下载及备份均在 `data/integrations/explorer-thumbnails`。移动程序文件夹后需要重新启用以更新 Windows 注册路径。Windows 自身维护的文件选择历史、回收站、系统缩略图和显卡驱动缓存仍由系统管理。
